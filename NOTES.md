# NOTES

The final model is a 4-layer, 176-dim decoder-only Transformer (RMSNorm, RoPE, SwiGLU, tied embeddings) with a 2,944-token byte-level BPE tokenizer, 1,995,312 parameters, trained for 2,000 AdamW steps. It scores 1.6678 BPB on the dev set, against 1.6779 for the same model with a 2,048-token vocabulary. The gain comes from the tokenizer: steps are capped, so packing more bytes into each token (3.65 bytes/token) lets every step see more text. The extra vocabulary also uses parameter headroom the 2,048 model left under the 2M cap. In 600-step ablations, Muon converged far faster than AdamW (1.765 vs 2.020 BPB) and multi-query attention matched or beat full attention with 9% fewer parameters. Deeper-narrower models and dropout both hurt, because the model is still under-fitting after about 4 passes over the corpus. A full 2,000-step Muon run is the most promising next step. The base code is Priyanshu Pandey's submission; see the Credits section of the README.
